======================================================================
CORE MECHANISM THAT MUST SURVIVE
======================================================================

SOLE prevents a canonical issuer book from granting two materially overlapping exclusive rights merely because their natural-language scopes are worded differently.

A reservation has:
- immutable issuer/book binding,
- immutable holder,
- right scope,
- product scope,
- territory,
- channel,
- audience,
- [start_at,end_at) interval.

Time overlap is deterministic.

For each time-overlapping incumbent, GenLayer consensus classifies five semantic dimensions using only:
- EQUIVALENT
- CONTAINS
- CONTAINED_BY
- OVERLAPS
- DISJOINT
- AMBIGUOUS

The contract derives:

    if ANY dimension == DISJOINT:
        pair = CLEAR
    elif ANY dimension == AMBIGUOUS:
        pair = AMBIGUOUS
    else:
        pair = CONFLICT

Overall:
- any conflict -> BLOCKED
- otherwise any ambiguity -> AMBIGUOUS
- otherwise -> READY

The LLM must NEVER directly output "grant", "deny", "winner", "legal", or "safe".

Other invariants:
- holder must accept exact immutable reservation;
- one canonical book per `(owner, domain_key)` inside this deployment;
- model/infra failure is an explicit retryable non-decision, never CLEAR;
- granting/releasing increments `book.epoch`;
- final grant requires assessment epoch == current epoch and exact comparison-set hash;
- issuer cannot revoke a granted right;
- only holder may release;
- book pause must not erase existing grants;
- consumer binds exact SOLE address/book/hash/holder/reservation hash;
- replay must fail.

Do not weaken these to simplify live testing.
